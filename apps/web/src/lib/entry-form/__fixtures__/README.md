# entry-form-autofill テスト fixture

実際に主催者から配布された空の申込書テンプレを `build-fixtures.mts` で PII 除去
したもの。**構造（シート・結合セル・数式・入力規則・書式）は実物そのまま**で、
差し替えたのは主催者担当者の実名・実メールアドレス・団体名だけ。合成 xlsx では
結合セルや入力規則が「自分のスクリプトが書いたものだけ」になり、記入エンジンの
非破壊性（AC-10）を検証できないため、実物由来にしている。

再生成: `SRC_DIR=<入力ディレクトリ> pnpm exec tsx build-fixtures.mts`
（入力の取得手順は `build-fixtures.mts` の冒頭コメント）

## 各 fixture の構造

### standard.xlsx — 標準型（最多数派）
- シート: `Sheet1`（1枚）
- ヘッダ欄: `A3`〜`A8` がラベル（都道府県／所属会名／申込責任者氏名／連絡先電話番号／連絡先E-Mail／振込名義人）。記入先は同じ行の右隣セル
- 明細ヘッダ行: **r11** — `A`=No / `B`=参加級 / `E`=段位 / `F`=氏 / `G`=名 / `H`=ふ り が な / `I`=出場回数（「2026年度　各級申込開始日出場回数」）/ `J`=備考
- 記入開始行: **r12**
- No 列に数式: `A13` = `=A12+1`、`A14` = `=A13+1`（**上書き禁止セルの検証に使う**）
- 段位の入力規則: `E` 列に list `"初段,2段,3段,…,10段"`（→ danFormat `n段`）。入力規則は 640 セル分
- 結合セル 6 / `B10` に「リスト選択」の注記
- 申込先メール: `F37` に `申込先：　entry@example.invalid`（AC-12 の抽出対象）

### split-kana.xlsx — 姓名・かなが別列の2段ヘッダ型
- シート: `シニア選手権大会申込書`
- 明細ヘッダは**2行**: r5 が大見出し（氏名／ふりがな／…）・r6 が小見出し（姓／名／姓／名／…）
  - `B`=氏(姓) / `C`=名 / `D`=ふりがな姓 / `E`=ふりがな名 / `F`=所属会 / `G`=段位 / `H`=参加級 / `I`=参加料 / `J`=備考
- 記入開始行: **r7**（10 行分）
- 段位の入力規則: `G` 列に list `"初,二,三,四,五,六,七,八,九,十"`（→ danFormat は漢数字）
- 集計数式: `I17` = `=SUM(I7:I16)`（**上書き禁止**）
- 申込先メール: `D24` に `Emailアドレス：entry@example.invalid`
- 結合セル 10

### shifted.xlsx — 列位置がずれた変形型
- シート: `申込書（D級の部）`
- ヘッダ欄はラベルが「所属会名：」「申込責任者：」「E-mail：」「電話番号：」形式で `C4`/`C6`/`C7`/`C8`。都道府県・振込名義人の欄が**無い**
- 明細ヘッダ行: **r12** — `B`=No（r13 から連番）/ `C`=参加級 / `D`=氏 / `E`=名 / `F`=ふりがな / `H`=参加資格事由
- **段位列が無い**・出場回数列も無い（→ 段位/出場回数は記入対象外になる系統）
- 参加級の入力規則: `C13`〜 に list `"D"` 固定（→ このシートの対象級は D と判定できる）
- 申込先メール: `H9` に `entry@example.invalid`（元は richText）
- 結合セル 0・数式 0

### multisheet-grades.xlsx — 級別複数シート型（シート名から級が判る）
- シート: `C級` / `D級`（同一レイアウト）
- 明細ヘッダ行: **r7** — `A`=No. / `B`=段位 / `C`=氏 / `D`=名 / `E`+`F`=ふりがな（見出しが「ふ　　　り」「が　　　な」の2セルに割れている）/ `G`=所属会（学校名）
- 記入開始行: **r8**
- ヘッダ欄: `F3`=代表者名 / `F4`=電話番号 / `F5`=e-mail のラベル
- 表題 `A1` に「（C級の部）」「（D級の部）」
- 入力規則 0・数式 0・結合セル 1（表題）

### multisheet-ambiguous.xlsx — 級別複数シートだが級名が非標準
- `multisheet-grades.xlsx` と**同一構造**でシート名だけ `上級` / `中級`
- A〜E 級へ機械的に対応させられない → ヒューリスティックは**低信頼**を返し、
  AI フォールバック／手動マッピングへ回す系統（AC-7 の入口）
