## 4. mirror_name_mismatch / self / contradiction（(c) 576件）

いずれも「候補は見つかったが安全ゲートで保守的に skip した」行＝**原本の略記/誤記の疑い**。totals中立の UPDATE で是正しうる。

- **mirror_name_mismatch 490**: 相手側に逆結果の同round行が存在するのに、両者の名が相互参照しない
  （例: 片側が「姓(頭文字)」略記）。**宇佐神宮 t702=103 / t726=100 が突出**（「姓(頭文字)」形式・単一原因の可能性）。
  兵庫t801=57・大分t789=55・香川t673=21・桑名t650=20 と続く。宇佐神宮を最初に精査すると費用対効果が高い。
- **self 54**: 相手名＝自分の名前（原本の誤記）。小中学生t680=17・福井t190=7 ほか。真の相手は原本で特定要。
- **contradiction_same_dir 31**: 結線すると両者 win/win（or lose/lose）になる＝原本の勝敗誤記。福井小中t641=15 が集中。
- **mirror_points_elsewhere 1**: 米国t1284。
