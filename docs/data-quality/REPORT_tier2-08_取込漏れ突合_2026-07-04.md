## 1. 突合方法

1. マトリクス文書の147行から (series, year, edition) を抽出。
2. `series_coverage.csv`（series_coverage.py が HP索引を正規化して構築した個人戦専用の「開催回×取込状況」表）と、シリーズ名の正規化キー（`大会`/`戦` 語尾を除いた mkey）＋回次番号で突合。146/147 が直接一致、1件（日タイ交流バンコク大会 第10回, 2014）は索引レンジ外で不一致（4節参照）。
3. `REPORT_individual_coverage_2010_2026.md` の大会別「欠落回次と理由」表をパースし、128/147 行に理由ラベル（HPに結果ファイル無 / PDF・Word未パース / 特殊形式・未取込要確認）を付与。
4. 残る19行（`series_coverage.csv` 側で IN_CORPUS=取込済 表示、または理由表に載っていない行）は個別に検証。うち14行は hp_filetypes=none（HP自体に結果ファイルなし）と矛盾しており、`series_coverage.py` の「同日開催の別大会が corpus 内にあれば inc=True にする」日付フォールバック仕様による誤検出と判明（3節参照）。
5. 特殊形式・未取込 8件、および IN_CORPUS かつファイル実在の4件（テブル1・三原1・茨城3・沖縄2）は、実ファイルを Python（xlrd/openpyxl）で直接開いて中身を確認（読み取りのみ、DB操作なし）。

## 3. 重要な発見: series_coverage.csv の IN_CORPUS フラグ誤検出（18件）

147件のうち18件は series_coverage.csv が status=IN_CORPUS（＝2026-06-26時点で取込成功しリハDBに投入済のはず）と表示していたが、本番matrix（2026-07-03時点）では「○」（データなし）のままだった。内訳:

- 14件: hp_filetypes=none（HP自体に結果ファイルなし）と矛盾。series_coverage.py の実装を確認したところ、「同一日付の（別）大会が解析コーパスに存在すれば inc=True にする」という日付一致フォールバックが原因の誤検出と判明。実体は原本なし＝(c)へ分類し直した。
- 2件（初段認定茨城大会 第3回・沖縄県大会 第2回）: 実体はPDFのみで、Excel/HTMLパーサでは処理できない。同じ日付フォールバックの誤検出と推定。(b)へ分類。
- 1件（テブル大会 第1回）: 実際にIN_CORPUS（一度は解析コーパスに載った）が、スコープ外種目のため意図的除外。(e)。
- 1件（初段認定三原大会 第1回）: 実ファイルは暗号化されており本来パース不可能なはず。IN_CORPUS表示の原因は未特定（同じ誤検出パターンの可能性）。(b)。

なお、series_coverage.csv は逆方向の見落とし（本当は取込済なのにNOT_IN_CORPUS表示）も1件確認: ドイツミュンヘン大会 第1回（2節(a)参照）。RECOVERY_MAP の名寄せキー不一致というスクリプトバグが原因。

→ series_coverage.csv の status/in_corpus 列は単体で信用せず、hp_filetypes 列（HP索引由来で信頼度が高い）と突き合わせて判断する必要がある。今回はこの方針で全147行を再分類済み。

## 4. 注意点・次アクションへの申し送り

1. 本フェーズの最優先アクションはDB確認: ドイツミュンヘン大会 第1回（2節(a)）が既にDBに存在するか、存在するならeditionにリンクされているかを確認する。存在しなければ karuta_results/2019/1316_Munich_shosai.xlsx から再投入。
2. 順位戦パーサの投資判断: b-1の6件は全国選抜大会（既知の同種課題、全体で16回次中12回がこの形式）と合わせるとまとまった回収規模になる。本タスクのスコープ外だが、パーサ拡張のROIとして次フェーズで検討価値あり。
3. PDF/Word 36件・暗号化1件: 既存方針どおり別スコープ（構造化見送り中）。追加アクションなし。
4. 日タイ交流バンコク大会 第10回(2014)の付番不整合: tournament_seriesマスターの回次リストが、今回突合に使ったHP由来コーパス索引（series_coverage.csvの元になった {year}_plan.csv 等）でカバーされていない回次を含んでいる可能性がある。同種の不整合が他シリーズにもないか、editions マスター構築時の一次ソースを別途確認することを推奨（本フェーズのスコープ外、次フェーズ申し送り）。
5. テブル大会2件はマトリクスの「147回次」カウントから除外すべき（2節(e)）。
6. 会員ページへの再アクセスは今回一切行っていない（指示通り）。0-1節で完全性が実証済みのため、(c)分類の88件について再harvestしても新たな発見は期待できない。
