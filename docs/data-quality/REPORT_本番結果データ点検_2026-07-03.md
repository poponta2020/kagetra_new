**救済可能性**: 原本に両側の記録がある場合はパーサ改修＋再取込で回収可能。原本自体が片側のみ（勝ち上がり表など）の場合は、ミラー行の機械生成（相手側視点の行を反転生成）で補完可能。

### 検査値の定義（CSV列）

| 列 | 意味 |
|---|---|
| opp_unresolved_normal | status=normal で opponent_participant_id が null の対戦数 |
| mirror_missing | 相手側の対応行（同級・同round・参加者と相手を入替えた行）が存在しない対戦数 |
| result_conflict | 相手側行と勝敗が矛盾（両者win/両者lose）する対戦数 |
| same_round_dup | 同一round内に同一参加者が2回以上現れる組数 |
| bad_progression | 次roundの対戦数が当roundより増えている箇所数 |
| rounds_distinct / round_max | 実在roundの種類数と最大round（差があればround欠番） |
| participants_no_match | 対戦を1つも持たない参加者数 |
| p_bracket_champ_cnt | derived_bracket=1（優勝）の人数（正常は1） |
| p_name_* / opp_name_* | 選手名・相手名のゴミ文字検査（数字・記号・所属会風） |
| score_out / score_null_normal | 枚数差の範囲外(0未満/26以上)・normal勝敗ありで枚数null |
