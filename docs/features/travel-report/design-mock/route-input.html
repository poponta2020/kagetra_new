ホーム大会申込管理統計メール設定
出場日の後に移動がある例（十和田→苫小牧→札幌）。同じ日に「出場」と「移動」が並ぶ。代理入力は見出しの名前と朱の注記だけが違い、フォームは本人と同一。

R2 で変えたこと

  • プロフィールは表示のみ。 学部等名・学年・電話は会員 DB の値をそのまま1行で出す（「修正」で開く）。欠けている人だけ最初から入力欄を開く。
  • 行き・帰りを別々の2択に。 「帰省先から出場」だけでなく「そのまま帰省」を表現できる。組み合わせは4通りで、既定行の有無と出場チップの文言だけが変わる。
  • 既定の往路・復路は本人の出場日を基準（前日／翌日）にする。大会の初日・最終日ではない。
  • R3: 行き・帰りに「その他」（旅行先・学会先などの地名を自由記述）。既定行はその地名から／へ。
