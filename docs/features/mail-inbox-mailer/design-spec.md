# mail-inbox-mailer デザイン仕様（メール詳細の統合処理フォーム）

対象: `/admin/mail-inbox/mail/[id]` の処理エリア。ロジック・遷移・データは
[requirements.md](requirements.md) が正典。**視覚の正は `design-mock/`** で、本書は
レイアウトを言葉で再記述しない。

## 採用した方向性 — A案（1画面の縦フロー）

種別セグメントを最上部に置き、選んだ種別に応じて**必要な入力欄だけがその下に生える**。
ステップ遷移を持たず、常に全体が1スクロールで見渡せる。

| カード | 状態 |
|---|---|
| `a-initial.html` | 開いた直後（種別=未選択・大会未選択）。「試合結果の取込」が下に出る |
| `a-notice.html` | 種別=大会案内。対象・名簿・配信の欄が消えて AI 抽出だけになる |
| `a-roster.html` | 種別=確定名簿。**最も情報量が多い基準ケース**（添付2件採用＋級指定＋配信ON） |
| `a-link.html` | 種別=未選択＋大会紐付け＋配信ON・本文添付OFF（組合せ表の訂正版） |
| `a-nobinding.html` | LINE グループ未紐付けで配信を選べない状態 |
| `sheet-picker.html` | 「大会を選ぶ」ボトムシート（`a-initial` の `大会を選ぶ` から開く） |

### B案（3ステップウィザード）を採らなかった理由
1画面あたりは軽くなるがタップが2回増え、②③でメール本文が画面から消える。名簿の級を
本文と照合しながら選ぶ場面で不利。ラウンド1でユーザーが A案を選択（カードは削除済み）。

### 「実行すると」要約ブロックを置かない（ラウンド2でユーザー判断）
実行前サマリーは一度採用したが撤回した。**藍地の要約枠は置かない。** 実行内容は各入力の
サブラベル（例: 配信チェックの「配信先: 札幌AB のグループ」）で伝える。
大会案内カードだけは AI 抽出の挙動が入力欄から読み取れないため、`.hint` の補足文1行を残す。

## 確定した意匠

- 種別は**セグメント4分割**（未選択 / 大会案内 / 申込名簿 / 確定名簿）。選択中は brand 塗り
- 種別ピルは `pill brand`（藍）。未選択のメールには種別ピルを出さない
- 選択済みの大会は brand 枠のチップ（`.picked`）で、開催日レンジ＋申込状態を副次行に出す
- 級は A〜E のトグルチップ。**「取込単位（グループ統一／級別）」のラジオは置かない** —
  「級を1つも選ばない = グループ全体の名簿」をヒント文1行で表す
- 採用対象外の添付は消さずに `surface-alt` で沈める（`.frow.dim`）
- LINE 未紐付けはチェックボックスを無効化し、`neutral` 帯で理由と行き先リンクを出す
- 「対応不要」はフォームカードの**外**に ghost ボタン。実行ボタンと色で分ける
- 「試合結果の取込」は種別=未選択のときだけ、フォームより下に独立ブロックで置く

## 必要データ（仮データの実配線先）

モックの値はすべて架空。実装時に以下へ差し替える。

| モックの値 | 実データ |
|---|---|
| 「札幌AB」「道南CDE」等 | 申込グループの表示名（通称ベース。`deriveEntryGroupName` 由来） |
| 「2026-09-13〜2026-09-14 ・ 申込済み」 | グループ内の開催日レンジ + `entryStatus` |
| 「確定名簿 未取込」（シートのみ） | 当該グループ・当該種別の採用済みファイル有無 |
| 添付名・サイズ | `mail_attachments.filename` / `sizeBytes` |
| 冒頭メッセージのチップ | `BROADCAST_LEAD_PRESETS` |
| 発表日の placeholder 内の日付 | メール受信日 |
