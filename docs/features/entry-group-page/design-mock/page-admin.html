この画面で決めていること

  • フロー帯を sticky ヘッダーに入れた。「まず目に入るべきは締切と進行のサマリー」というユーザー判断に従い、下へスクロールしても消えない。日ページ（event-detail-redesign）と同じ型なので、行き来しても目が迷わない。
  • 運営操作は既定=閉の <details>。開いた直後に見えるのは ヘッダー → フロー帯 → 日程 → 進行管理の見出しだけ。日ページで確立した「既定表示では今どの段階かだけが見える」を踏襲する。
  • 進行管理を開いても日ごとのトグルは無い。状態の切り替えは必ず日程表で日を選んでから。「どこで申込済にするのか」が1箇所に定まる。
  • 共通項目は7項目ちょうど。実コードの PROPAGATABLE_FIELD_KEYS と同じ集合で、ここでの保存が全日に効く。
  • 名簿・オープンチャットはここにも日ページにも出る。同じグループ帰属のデータなので、どちらから見ても同じ。
  • 級別参加料（A/B 2,500・C/D 2,000・E 1,500）は協会規定の実値。振込総額はそこから導出した仮の集計。
