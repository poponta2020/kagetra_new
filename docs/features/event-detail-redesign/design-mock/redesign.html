リデザイン案 — 罫線＋余白主導（脱カード）

方向性の宣言（design.md 2.5-1）：和紙 × 藍墨／エディトリアル寄り／この画面のアンカーは「9/6(日) 広島CDE」のタイトル1つ。

カードを剥がした箇所（2.5「読む情報を箱に入れてはいけない」）：情報テーブル・備考・進行管理・LINE 配信・配信履歴・級別配信・名簿・参加者。すべて下線付き見出し＋余白＋罫線に置き換えました。カードを1枚はがしても情報は読めるので、箱は不要でした（2.5 リトマス試験）。

カードを残した箇所：関連メール2件のみ。1件ずつが「タップして開く独立した物体」なので 2.5「使ってよい」に該当します。この画面で唯一の箱なので、逆にここがタップできることが伝わります。

管理者ビュー最上部に申込フロー（仮）：会内締切 → 大会申込 → 抽選 → 支払 → 開催 を横一列に（両ビュー共通）。完了は藍の塗り点、進行中は藍の輪、未着手は砂の点、支払（未払）は朱の輪、開催（ゴール）は墨の大きめの輪。状態はビューごとに変えています（管理者=poponさん 申込済/未払、会員=山田さん 未回答。会員側は支払の朱を出しません）。箱を使わず点と罫線とタイポだけで組んでいます。ステップ定義・状態判定は Claude Code 側で詰める前提の仮置きです。

採用した型：

  • 罫線セクション — セクションは Serif 18px の見出し＋1px 下線＋34px の余白だけで区切ります。当初はセクション間にも罫線を引いていましたが、見出しの下線と2本が近接して逆に構造が読みにくかったため撤去し、罫線は1セクション1本に統一しました。入れ子カードは全廃。
  • フラット表 — 罫線は行間のヘアラインのみ。日付・金額・定員は tabular-nums で桁を揃え、名簿の級は1文字で縦に通す（C/D/E）。
  • 余白主導サマリー — 参加者「5名」を Serif の大きな数字で。囲みません。
  • エディトリアル列 — 備考本文のみ Serif 16/1.9。読み物であることを字面で示します。
  • sticky 見出し — 日付＋大会名・会場名・申込フローを1塊で画面上部に固定。長い画面を下までスクロールしても、どの大会を見ているか・今どの段階かを失いません。3要素を個別に固定するとオフセット計算が壊れやすいため、1つのラッパーで固定しています。
  • 名簿は開閉トグル＋級タブ — 申込者名簿・確定名簿をそれぞれ折りたたみ、開くと級ごと（全体 / C / D / E）に絞り込めるタブを出します。12行が常時開いて画面を占める問題を解消し、級で見たいときにすぐ辿れます。名簿内は級の若い順に並べ替えました。

チップの羅列をやめた箇所（2.5 禁止リスト）：級別定員（C級ピル＋数字ピルの入れ子）→ 級と数字を1行に横並び（見出しと合わせて2行）。参加者（苗字＋級ピル ×5）→ 人数と名前を1行に（級は名前直後の小さな添え字）。名簿の「会員」バッジ → 所属の後ろに藍の小さな添え字。

名簿の取込フォームは撤去（確定）：名簿はメールからのみ取り込む方針のため、この画面は閲覧専用にします（管理者ビューも同じ）。実装では現行の Excel アップロード（RosterUploadForm / uploadRoster）を削除します。

確定名簿の空状態：確定名簿は「名前リスト」（組合せ表ではない）なので、文言を「申込者名簿と同じ形式で確定した出場者が並びます」に修正しました。

申込フローの未設定日：抽選日・支払締切などが NULL の大会では、ステップを消さず日付欄に「未定」と出します（下の状態バリエーション参照）。

ほか：日付を生 ISO（2026-09-06）から 8/5(水) 形式に。会場をタイトル直下に引き上げ、テーブルから外して冒頭で状況が掴めるようにしました（正式名称は不要なため非表示）。左右に 16px の余白を追加。

オープンチャット欄を新設（★今回の実装対象外・別スコープ）：DB に該当データが無く、スキーマ追加＋migration が必要なため、UI 案としてのみ残置します。トグルの見出し脇に「級別」／「全級」のバッジを出して、どちらの運用かを示します。級別なら級ごとの行、全級統一なら 全級 の1行だけになります。URL はそのまま表示（何が起こるか分かるように）。管理者は未設定の級が朱で「未設定」と出て、URL 編集もできます。会員は自分の級のぶんだけ表示。

比較用の現状再現は current.html に残しています。
