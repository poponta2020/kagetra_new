  • ボードの単位は名簿の写し: 正会員／准会員の区分ごとに並べ、行を開くと名簿の列が出る。紙を書くときはこの順で目を走らせる。

  • 差分の見せ方: 前（取り消し線・砂）→ 後（朱・太字）。変更のない項目は畳む。
  • 登録完了: sticky の外線ボタン。確認ダイアログで人数・氏名・不可逆を明示。
