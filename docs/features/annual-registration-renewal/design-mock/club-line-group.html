この画面で決めたいこと

  • Bot 選択の意味: 選んだ瞬間にプールから外れる。戻すのは朱のリンク。
  • URL 1本で登録: U… と C… を別々に入力させない。表示名は OAM と完全一致（ワーカーの照合キー）。
  • 捕捉状態を見せる: 未捕捉だとメンションが使えないことをここで知らせる。
  • 送信タスクは読むだけ: 再試行以外の操作は置かない（予約の中身は編集しない）。
