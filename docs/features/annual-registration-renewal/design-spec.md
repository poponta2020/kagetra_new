## 1. 対象と狙い
- **対象画面:** frontmatter の 5 画面（S1〜S3 新規、S4・S5 は既存画面の delta）
- **現状の不満:** 年度替わりの全日協登録確認を管理者が個別に聞いて回り、名簿に赤を入れて届出を手書きしている
- **狙い:** 会員が「開いて 2 択＋確認」で答え、管理者は名簿の写しに回答状況と差分が乗った画面を見ながら紙を書ける
- **主ユーザー / 主な使い方:** 会員＝自分の確認（年 1 回・数分）／管理者＝集計を眺めて紙を書く・未回答者を追う

## 2. 採用した方向性
- **方向性:** 1 案深掘り。S1 は「2 択カード → 名簿と同じ列順の行内修正 → 学年 1 行」、S2 は「集計 → 4 タブ → 正会員／准会員ごとの名簿の写し（開くと列・差分）」
- **不採用案と理由:** ウィザード型（登録可否 → 各項目 → 学年 を画面分割）は画面遷移が増え、名簿の列を一覧で確認する目的に合わないため最初から採らなかった。複数案の比較はしていない（画面の構造が全日協の名簿と既存の登録フォームで決まるため）
- **視覚の正:** `design-mock/`（カード: 年度確認（annual-registration-renewal） 配下の 5 枚）
  - `renewal-member.html` — S1（未回答・両セクション／最終学年の 3 択／登録しない／回答済み／学年のみ・全日協のみ）
  - `renewal-admin.html` — S2（未開始／進行中・未回答タブ／変更ありタブ／登録完了ダイアログ・完了後・代理回答）
  - `club-line-group.html` — S3（未設定／設定済み＋送信タスク）
  - `home-banner.html` — S4（3 断片）
  - `member-edit.html` — S5（公認資格の delta）
- **最終確認時の状態:** R1（2026-09-09）。全 HTML を 440〜1700px 幅で PNG 化し横スクロール無し・トークン外の色ゼロを確認。ユーザー承認「これで確定でいいです」

## 3. 視覚の正に現れない設計判断
- **S1 の 2 択は名簿の列より上**。「登録しない」を選ぶと列は開閉行に畳まれ、必須欠落があっても回答できる（登録しない人に住所を埋めさせない）
- **S1 の行内修正**。行の「修正」で値が下線入力に変わる（別画面へ飛ばない）。未入力の行は最初から入力欄で、埋まるまで下のボタンは無効文言（「未入力の項目があります」）
- **会員区分・公認資格は読み取り専用行**として名簿の列の末尾に置く（名簿にある欄なので見せるが、本人は変えられない）。会員区分には導出根拠「3/31 時点で 20 歳以上」を添える
- **学年は「現在 → 4月から」の 1 行**が既定。最終学年だけ 3 択（進学／卒業／留年）のラジオ縦並び。進学は登録フォーム（S1 register）と同じ 所属→学部等名（候補つき）→学年 を続けて出す。最終学年以外の例外（サークルを離れる・学年を自分で選ぶ）はリンクで開く
- **回答済みの差分は本人にも見せる**（前＝取り消し線・砂、後＝朱・太字）。管理者の S2 と同じ表現
- **S2 の主集計は全日協（N / 31 確認済み）**、学年は同じ行の副集計で一段小さく。「該当する前年度登録会員の全員が終わったか」が主目的のため
- **S2 の行は正会員／准会員の区分見出しで分ける**（紙の名簿がその順）。行の右は状態語（未回答＝朱、変更ありタブでは変わった項目名＝藍）。開くと名簿の列を flat 表で、変更ありタブでは差分だけを出し「変更のない項目」を開閉行に畳む
- **代理回答は 2 択だけ**のダイアログ。項目の修正は既存の会員編集へ（差分は同じ導出で出る）
- **登録完了は sticky の外線ボタン**（主ボタンにしない＝毎日押すものではない）。ダイアログで「フラグを消す人数・未回答の氏名・不可逆」を 1 画面に
- **S3 はルーム URL を 1 本貼るだけ**で U…／C… を取り出す。表示名は OAM の見出しとの完全一致がワーカーの照合キーなので、人数の括弧を含めない旨を help に出す。グループ ID（webhook 側）の捕捉状態を badge で見せ、未捕捉ならメンションが使えない旨を添える
- **S3 の送信タスクは読むだけ**（再試行以外の操作なし）。分割したリマインドは同じ日の別行「(分割 2/2)」
- **S4 のバナーは既存 2 種と同じ行型**。名前の位置は「未回答のセクション名」だけ（年度は S1 の見出しに出る）。締切後も登録完了までは出し続け、右端の語は大会の未回答アラートと同じ規則（あとN日／本日締切／締切超過）
