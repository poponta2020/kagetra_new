# tournament_series 通称（short_name）案 — レビュー用

> **これは ② 大会一覧（年別）通称表示のためのレビュー資料です。** 下表の「提案略称」を
> 確認・修正してください。承認後、この表を正として migration（`ADD COLUMN short_name` ＋ 180 件の
> `UPDATE ... WHERE name = ...`）に確定します。`name`（正式名称）は一意キーで、DB 現物（本番＝
> `kagetra_rehearsal` と一致）そのままです。

## 表示のしくみ（重要）

年別一覧の行タイトルは次で合成します（**年別一覧のみ**。大会詳細/シリーズ/選手詳細は正式名称のまま）:

- `short_name` があり **開催級が 1 つ以上** → **`short_name` ＋ 開催級を A→E 順で連結**
  - 例: 大阪の大会で B・C 級開催 → **「大阪BC」**／多摩の A 級のみ → **「多摩A」**
- `short_name` があり **開催級が空**（名人戦・クイーン戦など A–E 外のみ） → **`short_name` のみ**
- `short_name` 未設定 or edition 未紐付き → **正式名称フォールバック**（現行どおり）

→ したがって **提案略称に級文字（A〜E）は入れません**（級は自動連結）。地名・通称の最短形にします。

## 命名方針

- 末尾の「大会」「杯大会→杯」を落として最短化。
- **初段認定◯◯大会 → 「初段◯◯」**（「初段」を残す＝同地名の通常大会〈会津/佐賀/兵庫…〉と区別するため）。
- **◯◯県選手権 → 「◯◯選手権」**（県大会と区別）。
- 同地名で「◯◯大会」と「◯◯県大会」が別系列で両方ある場合は、**県側に「県」を残す**（兵庫/千葉/熊本）。
- 級の付かない選手権・名人/クイーン予選は、そのままでも表示されるので通称のみ。
