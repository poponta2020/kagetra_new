つらいケースの扱い

  • 年跨ぎ: 年が変わる最初の月見出しにだけ右端に西暦（11px・薄墨）を出す。翌2月以降には出さない（毎見出しに年を付けると T-4 の「見出し=数字の装置」が薄まる）
  • 本日締切: 朱の塗りピル（出荷済み仕様のまま）。月見出しの藍太罫と同居しても喧嘩しないことを確認するためのケース
  • 3日以内: 数字のみ 19px（出荷済み仕様のまま）
  • 中止行: タイトル淡色＋中止ピル＋締切「—」（出荷済み仕様のまま）。日付ブロックは通常表示
  • 申込可否の二重符号: month-sections.html の round 2 編集（色帯＋大会名の太さ）をこちらにも反映。冬季DE・中止行は regular、他は太字
  • 見出し行の削除とフッター行: round 2 決定を反映。最終月のセクションの下に「過去のイベント →」「新規作成」（管理者のみ）の1行
  • 1件だけの月（02 FEB）でも見出しの重さは変えない（通年で見出しが均質＝ゼロ埋めの狙い）
