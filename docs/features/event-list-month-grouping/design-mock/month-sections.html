月区切り（T-4 モダン・グラフィック）— 開催日順のみ

ウィジェット探索（11ラウンド）で確定した案を、出荷済みの行仕様に合成したものです。

  • 月見出し: ゼロ埋め2桁数字 31px（詰め字間 -0.03em・藍）＋ 英字月名 11px（字間 0.1em）＋ 藍の太罫 2.5px。件数表記は入れない（ユーザー決定）
  • 日付ブロック: 行頭へ移動。日数字はゼロなし 19px、下に英字曜日 10px。日曜のみ朱・他曜日は淡墨。大会名の行から日付を除去
  • 申込可否: 3px 色帯（藍=申込可能／砂=不可）と大会名の字面の二重符号 — 大会名はどちらも墨（fg）で、申込可能のみ太字。色帯で一覧の左端をスキャンでき、名前の太さでも同じ情報が読める
  • 維持するもの: 締切3段階強調（通常15px・3日以内19px・当日=朱ピル）／参加者行（人数藍+苗字）／締切済は非表示
  • ページ見出し行は削除（h1「大会申込」・リンク・新規作成ボタンの行）。「過去のイベント →」と「新規作成」（管理者のみ表示）はリスト末尾のフッター行へ移設
  • 締切日順は現状のまま（月区切りしない。開催日と締切日の月が食い違うため）
  • 10月の2行（すすきのCD・全道A）は複数月の見え方確認用の架空データ
  • 英字（AUG/SUN/SAT）と日曜の朱・土曜の藍は装飾タイポとしての意図的例外（UI文言=日本語原則・朱=警告系原則に対する）
