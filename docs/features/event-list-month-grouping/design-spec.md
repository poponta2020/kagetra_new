## 2. 確定した delta（開催日順のみ）

1. **月セクション化**: 開催日順ソート時、行を開催月ごとに束ね月見出しを挿入する
2. **月見出し（T-4）**: ゼロ埋め2桁の月数字（31px・ゴシック・semibold・字間-0.03em・藍
   `--kg-brand`）＋英字月名 AUG/SEP…（11px・medium・字間0.1em・藍）＋下線に**藍の太罫 2.5px**。
   件数表記（2 EVENTS 等）は**入れない**（ユーザー明示指示）
3. **日付を左ブロックへ**: 各行の行頭（色帯の右）に 日数字（**ゼロなし** 19px・semibold・
   tabular-nums・幅34px中央揃え）＋英字曜日（10px・medium・字間0.08em）。
   **日曜=朱 `--kg-accent`・土曜=藍 `--kg-brand`**・平日は `--kg-fg-3`。
   大会名の行から日付表記を除去する
4. **申込可否の二重符号**（Round 2 ユーザー編集）: 3px 色帯（藍=canApply）に加え、
   **大会名の太さ**でも同じ情報を出す — canApply=太字(bold)／不可=regular。
   色は両方とも墨 `--kg-fg` のまま
5. **ページ見出し行の削除**（Round 2 ユーザー決定）: h1「大会申込」・「過去のイベント →」・
   「新規作成」の行を実装からも削除する。**「過去のイベント →」（藍リンク）と
   「新規作成」（管理者のみ・藍塗りボタン）はリスト末尾のフッター行へ移設**
   （左=過去のイベント／右=新規作成）
6. **年跨ぎ**: 年が変わる**最初の月見出しにだけ**右端に西暦（11px・`--kg-fg-muted`）。
   他の見出しには出さない
7. **締切日順はフラットな現行リストのまま**（開催月と締切月が食い違うため月区切りしない）。
   見出し行の削除とフッター行（5.）は**ソートに関係なく適用**

## 3. mock に現れない設計判断

1. **ゼロ埋めの振り分けが T-4 の骨格**: 月見出し（08, 09, 10…）は通年で数字幅が揃い
   「見出し=グラフィックの装置」になる。行の日付はゼロなしで実用に読ませる。
   日付ブロックは固定幅 34px + tabular-nums なので 1桁/2桁で列は崩れない
2. **二重符号は冗長性が目的**: 色帯（周辺視でスキャン）と太字（行を読んでいる時）の
   どちらでも「出られる大会」が判る。色覚に依存しない符号にもなる。
   **色帯と太字は必ず同じ条件（canApply）に連動させる** — 片方だけ変える改修は禁止
3. **英字（AUG/SUN/SAT）・日曜の朱・土曜の藍は意図的例外**: 「UI文言は日本語のみ」原則に
   対し日付の装飾タイポとして英字を使う。「朱=警告系」原則に対し日曜の朱・土曜の藍は
   カレンダー慣習として使う。ユーザー承認済み（2026-07-28）。実装・レビューで
   「規約違反」として直さないこと
4. **月見出しの藍太罫(2.5px)と本日締切の朱ピルの同居**は edge-cases.html で確認済み。
   藍=構造 / 朱=緊急 の軸分離が保たれる
5. **中止行**: タイトルは cancelled（`--kg-fg-3`）が太字指定より優先。日付ブロックは通常表示
6. 出荷済み仕様からの行の変更は「日付の移動」と「太さの二重符号」だけ。
   締切3段階（通常15px/3日以内19px/当日朱ピル）・参加者行・締切済非表示はそのまま
